## Learning Objective

By the end of this lesson, you will share one value between owners with `Rc<T>` and read its reference count.

## Explanation

**`Rc<T>`** (from `std::rc::Rc`) allows several owners of one heap value in single-threaded code. A **reference count** beside the value tallies live owners: `Rc::clone(&a)` (a **shallow copy** — new pointer, same data) bumps it; each drop lowers it; zero frees the value. Spelled-out `Rc::clone(&a)` advertises cheap sharing, unlike `a.clone()` which may hide a deep copy. Threads need **`Arc<T>`** (atomic counting); cycles need `Weak` to avoid leaks.

## Why It Matters

Graphs, shared configs, and trees need "owned from several places"; `Rc` says that with no collector, and the count exposes the sharing.

## Example

`a` and `b` point at the same `10`; the count reads 2 and both prints show the shared value.

## Code

```rust
use std::rc::Rc;
fn main() {
    let a = Rc::new(10);
    let b = Rc::clone(&a);
    println!("count: {}", Rc::strong_count(&a));
    println!("a: {a}, b: {b}");
}
```

## Code Explanation

- `Rc::new(10)` starts the count at 1; `Rc::clone(&a)` adds owner `b` with no deep copy; both drops at scope end free the value.

## Common Mistakes

- **Writing `a.clone()`**: hides cost — spell `Rc::clone(&a)`; **`Rc` across threads**: `Rc` is `!Send`, so use `Arc`.

## Best Practices

- Spell shared clones as `Rc::clone(&x)`; assert `strong_count` in tests when ownership flow is unclear.

## Exercise

What prints at each line? Verify with `rustc`:

```rust
use std::rc::Rc;
fn main() {
    let a = Rc::new(10);
    println!("{}", Rc::strong_count(&a));
    {
        let _b = Rc::clone(&a);
        println!("{}", Rc::strong_count(&a));
    }
    println!("{}", Rc::strong_count(&a));
}
```

## Solution

`1`, then `2`, then `1`:

```rust
use std::rc::Rc;
fn main() {
    let a = Rc::new(10);
    assert_eq!(Rc::strong_count(&a), 1);
    {
        let _b = Rc::clone(&a);
        assert_eq!(Rc::strong_count(&a), 2);
    }
    assert_eq!(Rc::strong_count(&a), 1);
    println!("counts ok");
}
```

`_b`'s drop restores 1; `a`'s later drop frees the value.
